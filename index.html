Master Password Guide

This is the only password you will ever need to remember. It protects everything else, so it must be strong.

  • Use a Passphrase: A sequence of random words is highly secure and easy to type.
  • Prioritize Length: Aim for 16 or more characters.
  • Keep it Unique: Never reuse a password from any other account or service.
